# Xan — Futuristic Portfolio + Network Lab

A responsive, single-page portfolio with:
- Futuristic dark interface and optional light theme
- English / Arabic interface toggle (RTL)
- Responsive mobile navigation and scroll reveal
- About, expertise, sample work, and contact sections
- Browser-based IP information, DNS lookup, and HTTP latency tools

## Run locally
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Customize
- Edit the profile text, skills, project descriptions, and social links in `index.html`.
- Edit Arabic translations in `translations` inside `app.js`.
- Replace the generated abstract avatar with a real profile image if desired.
- Update the title and metadata in `index.html`.

## Important notes
- The project cards are illustrative portfolio entries, not claims of completed client projects.
- The IP tool uses ipapi.co.
- DNS lookup uses Cloudflare DNS-over-HTTPS.
- Latency check measures browser HTTP request time, not ICMP ping or traceroute.
- These tools query third-party public services directly from the visitor's browser.
- No backend, account system, or visitor tracking is included.
