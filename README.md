# Personal Website
موقع شخصي متعدد الصفحات مبني بـ HTML وCSS وJavaScript ES Modules ومهيأ للنشر على Vercel.

## Structure
- `index.html` الصفحة الرئيسية
- `pages/` صفحات من أنا، المشاريع، تفاصيل المشروع، دفتر الأفكار، والتواصل
- `assets/css/` التصميم العام والمتجاوب
- `assets/js/modules/` التنقل والحركة واللغة ونموذج التواصل
- `assets/js/data/` بيانات المشاريع
- `assets/js/pages/` منطق صفحات المشاريع

## قبل الإطلاق النهائي
1. استبدل [اسمك هنا] و[اسمك] و[مدينتك] ببياناتك الحقيقية.
2. أضف بريدك الحقيقي مكان `YOUR_EMAIL@example.com` في `assets/js/modules/contact.js`.
3. راجع روابط المشاريع وحالاتها وحسابات التواصل.
4. أضف صورك الحقيقية داخل `assets/images/` عند توفرها.

لا يوجد backend أو تسجيل دخول. نموذج التواصل يستخدم mailto ولا يرسل إلى خادم.
